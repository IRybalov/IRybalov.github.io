Privacy Policy

Last updated: October 8, 2026

Hugo Apartment Bot is a private application used only by its owner.

Google user data

The application accesses Google Drive file names, metadata and file contents in folders selected by the owner. It may access Google Calendar data when calendar functionality is enabled.

How data is used

Google user data is used only to search, retrieve, index and upload documents, and to perform actions explicitly requested by the owner.

Data storage

OAuth credentials, a document search index and temporary file copies may be stored on the owner's private server. Access is restricted to the owner.

Data sharing

Personal data is not sold or used for advertising. Selected document text may be processed by OpenAI to provide search and assistant functionality. Requested documents may be delivered through Telegram.

Data deletion and access revocation

The owner can delete stored data from the private server and revoke the application's Google access at any time through Google Account security settings.
